## Editor (IDE)
* [VSCode](https://code.visualstudio.com):
    - Cross-platform (Windows, Mac, Linux, Web).
    - Eco-system for extensions.
    - Support almost programming language.
    - Key map and command are mature.
    - Code Agent (Github Copilot) integration
        (Easy selection for code snippets, symbols and code tools calling).

## Operating system (VM, Container)
* Windows 11: 
    - Using office software (MS Office, Adobe) in study and work.
    - Most of games are in this platform.
    - The GUI and user habits are mature.
    - WSL can make up for the disadvantages in package management and development.
* [Debian](https://www.debian.org/): Stable and general.
* [WSL(Windows Subsystem for Linux)](https://github.com/microsoft/WSL): The best Linux distributions.
* [VirtualBox](https://virtualbox.org)
* [Docker](https://www.docker.com/)

## Proxy
* [Sing-box](https://sing-box.sagernet.org):
    - Cross-platform (App: Windows, Android, ISO, Mac OS | Core: Windows, linux...).
    - JSON configuration file is general and high customizable.
    - Fast support for new protocol.
    - High performance (Written by Golang).

## 编辑器 (集成开发环境)
* [VSCode](https://code.visualstudio.com):
    - 跨平台 (Windows, Mac, Linux, Web)
    - 插件生态系统
    - 支持大部分的编程语言
    - 快捷键和命令功能完善
    - 编码智能体 (Github Copilot) 集成，
        (易于选择代码片段和符号以及编码工具调用)

## 终端
* [Windows Terminal](https://github.com/microsoft/terminal)
* [Powershell 7+](https://github.com/powershell/powershell):
    为 Windows 用户打造类似 Unix 的命令行体验
* zsh
* [ohmyzsh](https://github.com/ohmyzsh/ohmyzsh)

## 操作系统 (虚拟机、容器)
* Windows 11: 
    - 在学习和工作中使用办公软件 (MS Office, Adobe)
    - 大部分的游戏都在这个平台
    - 图形界面和用户习惯成熟
    - WSL 可以弥补其在软件包管理和开发方面的不足
* [Debian](https://www.debian.org/): 稳定通用
* [WSL(Windows Subsystem for Linux)](https://github.com/microsoft/WSL): 最好的 Linux 发行版
* [VirtualBox](https://virtualbox.org)
* [Docker](https://www.docker.com/)

## 代理
* [Sing-box](https://sing-box.sagernet.org):
    - 跨平台 (应用: Windows, Android, ISO, Mac OS | 内核: Windows, linux...)
    - JSON 配置文件通用和高度可定制化
    - 快速支持新协议
    - 高性能 (用 Golang 编写)
* [V2rayN](https://github.com/2dust/v2rayn)

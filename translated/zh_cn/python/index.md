Python 堪称开发者心目中最令人印象深刻的编程语言。

作为最受欢迎的编程语言，
[Python](https://www.python.org) 的地位毋庸置疑。
它广泛应用于网络爬虫、自动化脚本、AI 模型训练及调用等领域。
许多库和工具都会优先支持 Python。
若没有它，开发者将难以构建各种现代化的实用小工具。

如今，越来越多的 Python 开发者将代码打包并发布到 [PyPI](https://pypi.org) 上，
这意味着开发者需要阅读他人的代码并使用这些库。
因此，对 Python 版本及依赖项进行版本控制显得尤为重要。
在现代 Python 开发中，
开发者常使用 [uv](https://docs.astral.sh/uv) 来替代 [pip](https://pip.pypa.io)
作为[包管理器](/translated/zh_cn/python/language/packages_management)，
因为它还能额外管理 Python 版本。

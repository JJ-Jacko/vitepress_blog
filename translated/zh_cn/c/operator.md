## 按位与 `&`
转换成二进制，对齐每一位，同时为 1 才为 1，否则 0
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 1 0 0
```
5 & 6 = 4

## 按位或 `|`
转换成二进制，对齐每一位，其中一个为 1 则为 1，否则 0
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 1 1 1
```
5 | 6 = 7

## 按位异或 `^`
转换成二进制，对齐每一位，相同为 0，不同为 1
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 0 1 1
```
5 ^ 6 = 3 

## 左移 `<<` 右移 `>>`
转换成二进制，按照移数向高位或低位移动，移数为正整数，右移动过 0 位的忽略不计
```txt{3}
5: 1 0 1
-----------
3: 1 0 1 0
```
5 << 1 = 3

```txt{3}
5: 1 0 1
-----------
3: 1 0
```
5 >> 1 = 2

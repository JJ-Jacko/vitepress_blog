## 元字符
* `.` 除換行以外嘅任何字元
* `\w` 字母、數字、底線
* `\s` 空白字元
* `\d` 數字
* `\n` 換行字元
* `\t` Tab 字元
* `^` 字串開頭
* `$` 字串結尾
* `\W` 非字母、數字、底線
* `\S` 非空白字元
* `\D` 非數字
* `a|b` 字元 a 或字元 b
* `()` 組
* `[...]` 字元組入面嘅字元
    * [abcde123] 分別匹配 a、b、c、d、e、1、2、3
    * [a-zA-Z0-9] 分別匹配小寫 a 到 z、大寫 A 到 Z，同數字 0 到 9
* `[^...]` 非字元組入面嘅字元
    * [^abcde123] 匹配 a、b、c、d、e、1、2、3 以外嘅字元

## 量詞
* `*` 重複 0 次或更多次
* `+` 重複 1 次或更多次
* `?` 重複 0 次或 1 次
* `{n}` 重複 n 次
* `{n,}` 重複 n 次或更多次
* `{n,m}` 重複 n 次到 m 次

## 貪婪、惰性匹配
玩吃雞遊戲，晚上一齊打遊戲，做咩呢？打遊戲呀
### `.*` 貪婪匹配
#### 表達式
```
玩.*遊戲
```
#### 結果
玩 `吃雞遊戲，晚上一齊打遊戲，做咩呢？打` 遊戲

### `.*?` 惰性匹配
#### 表達式
```
玩.*?遊戲
```
#### 結果
玩 `吃雞` 遊戲

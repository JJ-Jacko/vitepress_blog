## 按位與 `&`
轉成二進制，將每一位對齊，兩個都係 1 先至係 1，否則係 0
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 1 0 0
```
5 & 6 = 4

## 按位或 `|`
轉成二進制，將每一位對齊，其中一個係 1 就係 1，否則係 0
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 1 1 1
```
5 | 6 = 7

## 按位異或 `^`
轉成二進制，將每一位對齊，相同就係 0，唔同就係 1
```txt{4}
5: 1 0 1
6: 1 1 0
---------
4: 0 1 1
```
5 ^ 6 = 3 

## 左移 `<<` 右移 `>>`
轉成二進制，按照移位數向高位或低位移動，移位數係正整數，右移越過 0 位嘅部分唔計
```txt{3}
5: 1 0 1
-----------
3: 1 0 1 0
```
5 << 1 = 3

```txt{3}
5: 1 0 1
-----------
3: 1 0
```
5 >> 1 = 2

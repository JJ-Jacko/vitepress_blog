| 模組 | 必填 | 可以有多個 | 選項 / 例子 | 描述 |
| :-: | :-: | :-: | :-: | :-: |
| Type | ✔️ |  | `Feature`、`Refactor`、`Bug`、`Test` |  |
| Labels |  | ✔️ | `CLI`、`Service`、`Documentation` | 項目範圍 / 組件 |
| Title | ✔️ |  | 實現全局 `--help` 同 `--version` 選項 |  |

### 第一個留言
| 標題 | 描述 |
| :-: | :-: |
| Description | 如果標題未能清楚表達問題，請詳細描述個問題 |
| Environment | 作業系統、環境變數、Runtime、Packages、Git commit |
| Modifications | 會修改啲乜嘢？ |
| Expected behavior | 詳細描述修改前後有咩分別 |

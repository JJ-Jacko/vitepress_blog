## 編輯器 (整合開發環境)
* [VSCode](https://code.visualstudio.com):
    - 跨平台 (Windows, Mac, Linux, Web)
    - 擴展插件生態系統
    - 支援幾乎所有編程語言
    - 快捷鍵及命令功能成熟
    - 編碼智能體 (Github Copilot) 集成
        (易於選擇代碼片段、符號及編碼工具調用)

## 操作系統 (虛擬機、容器)
* Windows 11: 
    - 在學習及工作中使用辦公軟體 (MS Office, Adobe)
    - 大多數遊戲在該平台運行
    - 圖形介面及用戶習慣成熟
    - WSL 可彌補軟體包管理及開發方面的不足
* [Debian](https://www.debian.org/): 穩定通用
* [WSL(Windows Subsystem for Linux)](https://github.com/microsoft/WSL): 最佳 Linux 發行版
* [VirtualBox](https://virtualbox.org)
* [Docker](https://www.docker.com/)

## 代理
* [Sing-box](https://sing-box.sagernet.org):
    - 跨平台 (應用: Windows, Android, ISO, Mac OS | 核心: Windows, linux...)
    - JSON 配置文件通用且高度可自訂
    - 迅速支援新協議
    - 高性能 (以 Golang 編寫)
* [V2rayN](https://github.com/2dust/v2rayn)

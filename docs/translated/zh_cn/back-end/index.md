后端开发是程序员群体中的一个庞大种类。

传统的后端开发是对数据库的 CRUD(创建、读取、更新、删除)，
编写业务代码和设计对前端友好通用的 [RESTful API](https://en.wikipedia.org/wiki/REST)。
随着业务的扩大将系统设计成分布式的，
利用各种中间件优化流程，
将业务代码逐渐拆成无状态的微服务。

如今的后端开发需要顺应 AI 的浪潮，
这意味着编写面向大语言模型的接口 [MCP server](https://modelcontextprotocol.io)
或者是利用 [OpenAI SDK](https://developers.openai.com/api) 做 Agent 开发。

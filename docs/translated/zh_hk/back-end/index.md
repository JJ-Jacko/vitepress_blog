後端開發喺程式員入面，算係一個好大嘅類別。

傳統嘅後端開發，不外乎對資料庫做 CRUD(建立、讀取、更新、刪除)，
寫業務邏輯 code，同埋設計一啲對前端友善又通用嘅 [RESTful APIs](https://en.wikipedia.org/wiki/REST)。
隨住業務越嚟越大，仲要將系統設計成分佈式架構，
用各式各樣嘅 middleware 去優化流程，
同埋逐步將業務 code 拆成無狀態嘅 microservices。

去到今時今日，後端開發都要順住 AI 呢個浪潮走。
即係要額外寫 [MCP server](https://modelcontextprotocol.io) 作為俾大語言模型嘅接口，
又或者用 [OpenAI SDK](https://developers.openai.com/api) 去做 Agent 開發。

## Format
< Type >( Range ): < Description >
### Types
* `feat` add a new feature
* `fix` fix a bug
* `build` update build system
* `chore` update non-core code
* `docs` update documentation
* `test` update test files
* `refactor` refactor code (no feature, no bug fix)
### Scope
* `doc` project description files like `README.md` and protocol/spec files

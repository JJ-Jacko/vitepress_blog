## Key map
* `k` Pp
* `j` Down
* `h` Left
* `l` Right
* `gg` First line
* `G` Tail line
* `/` Search
* `w` Write
* `q` Quit
* `q!` Force quit
* `:x` / `:wq` Write & Quit

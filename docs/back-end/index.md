Back-end development is a broad category within the programming world.

Traditionally, it involves CRUD(create, read, update, delete) operations on database,
writing bussiness logic, and designing front-end-friendly [RESTful API](https://en.wikipedia.org/wiki/REST).
As systems grow, backend work also includes building distributed architectures,
using various middleware to optimize workflows,
and gradually splitting business code into stateless microservices.

Nowadays, backend development needs to embrace the AI wave.
This means writing [MCP server](https://modelcontextprotocol.io) as interfaces for LLM,
or building agents using the [OpenAI SDK](https://developers.openai.com/api).

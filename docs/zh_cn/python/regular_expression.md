## 元字符
* `.` 除换行以外的任意字符
* `\w` 字母、数字、下划线
* `\s` 空白符
* `\d` 数字
* `\n` 换行符
* `\t` 制表符
* `^` 字符串的开始
* `$` 字符串的结尾
* `\W` 非字母、数字、下划线
* `\S` 非空白符
* `\D` 非数字
* `a|b` 字符 a 或 b
* `()` 组
* `[...]` 字符组中的字符
    * [abcde123] 分别匹配 a、b、c、d、e、1、2、3
    * [a-zA-Z0-9] 分别匹配小写 a 到 z、大写 A 到 Z、数字 0 到 9
* `[^...]` 非字符组中的字符
    * [^abcde123] 匹配非 a、b、c、d、e、1、2、3

## 量词
* `*` 重复 0 次或更多次
* `+` 重复 1 次或更多次
* `?` 重复 0 次或 1 次
* `{n}` 重复 n 次
* `{n,}` 重复 n 次或更多次
* `{n,m}` 重复 n 次到 m 次

## 贪婪、惰性匹配
玩吃鸡游戏，晚上一起打游戏，干嘛呢？打游戏啊
### `.*` 贪婪匹配
```表达式
玩.*游戏
```
玩 `吃鸡游戏，晚上一起打游戏，干嘛呢？打` 游戏

### `.*?` 惰性匹配
```表达式
玩.*?游戏
```
玩 `吃鸡` 游戏

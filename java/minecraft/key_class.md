## Items
### ItemIds
Register vanilla items ids.
* Package: net.minecraft.references
### Items
Register vanilla items.
* Package: net.minecraft.world.item

## Blocks
::: tip
* `BlockItemIds` contains the IDs of block items, which allow players to obtain and place most blocks.
* `BlockIds` contains the IDs of blocks themselves, including blocks without a corresponding block item,
    such as water, lava, and fire.
:::
### BlockItemIds
Register vanilla block items ids.
* Package: net.minecraft.references
### BlockIds
Register vanilla blocks ids.
* Package: net.minecraft.references
### Blocks
Register vanilla block items and blocks.
* Package: net.minecraft.world.level.block
